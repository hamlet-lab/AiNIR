# ChatGPT Library reconciliation — 2026-08-16

## Repository role

`ainir` is the bounded public v1.0 RC candidate demo and is **not** the full private research archive.

## Cleanup consequence

Library copies of public-demo source, public docs, generated demo outputs, and handoff packages that are fully reproducible from this repository may be deleted after verification.

However, do not delete private research artifacts merely because a public repository exists. The README explicitly excludes the larger private review package, extended workflow suite, private reports, and enterprise policy packs.

## Preserve / migrate first

- private research evidence not present in `ainir`;
- private policy/review packages whose conclusions are not fully represented in the private RC repository;
- unique measured external validation results;
- any unpublished provenance needed for future claims.

Public-demo transfer ZIPs and repeated RC packaging artifacts should be treated as low-value once their source and claim boundary are reproducible from GitHub.

## Safety boundary

This reconciliation does not broaden AiNIR's semantic-verification claim and does not convert RC/demo status into production or v1 final status.

`Library artifact -> public/private scope -> repository coverage -> unique evidence? -> migrate/keep/delete`.

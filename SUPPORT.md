# Support

Use GitHub issues for reproducible bugs, documentation defects, conformance cases, and bounded profile proposals.

Include the AiNIR version or commit, Python version, operating system, exact command, minimal input, expected decision, actual decision, and relevant rule or gate IDs. Remove credentials and private data before posting.

Questions about production deployment, enterprise policy packs, private archives, AIVL/LEP implementation, or unsupported downstream runtimes are outside the public repository's support scope.

Security-sensitive reports must follow `SECURITY.md` rather than a public issue.
